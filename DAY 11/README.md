# DAY 11 — Coming Soon Landing Page

This folder contains a production-ready "Coming Soon" landing page with:

- High-performance animated particle background (pure CSS)
- Neon flicker headline effect
- CSS typewriter subheader
- Responsive masonry-style gallery (CSS Grid)
- Grayscale-to-color hover transitions
- Accessible modal for email notification (minimal JS)

How to view:

1. Open [DAY 11/index.html](DAY 11/index.html) in a browser.
2. Click "Notify Me" to open the modal.

Notes:
- All content is self-contained; placeholder SVG screenshots are in `assets/screenshots`.
- For production integrate form submission endpoint in `script.js` form handler.
