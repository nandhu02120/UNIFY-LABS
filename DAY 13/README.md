Day 13 — JavaScript Basics Demo

Files created:
- index.html — loads `script.js` in the browser.
- script.js — contains the JavaScript demo with console output and `typeof` checks.

How to run

- Browser: open `index.html` in your browser and open the developer console (F12 / Ctrl+Shift+I) to view the output.
- Node.js: run `node "script.js"` from inside the `DAY 13` folder.

What the script demonstrates

- `let` and `const` variable declarations
- basic arithmetic (addition, multiplication, remainder)
- storing results in variables and logging descriptive messages
- string concatenation for a personalized welcome message
- using `typeof` to inspect data types
